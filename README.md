# Mmakau Community Library Website

This is a simple, mobile-friendly website based on the information displayed on the library notice.

## Included
- `index.html` — main library information page
- `styles.css` — responsive styling
- `script.js` — automatically displays whether the library is currently open/closed based on the stated weekday hours
- `assets/logo.jpg` — cropped logo from the supplied notice photo
- `qr-generator.html` — generates a QR code once you have the website's public URL

## Publish it for free with GitHub Pages

1. Create/sign in to a GitHub account.
2. Create a new repository, for example `mmakau-community-library`.
3. Upload all files and the `assets` folder.
4. In the repository, open **Settings → Pages**.
5. Select **Deploy from a branch**, choose the `main` branch and `/ (root)`.
6. GitHub will provide a public address similar to:
   `https://YOUR-USERNAME.github.io/mmakau-community-library/`
7. Open `qr-generator.html` on the published site.
8. Paste the public `index.html` address into the generator.
9. Generate the QR code and save/print it.
10. Replace the old notice QR code with the new one.

## Important
The email address currently displayed is `mmakaulibrary@gmail.com`, matching the supplied notice.

Before public launch, confirm the official library/municipality logo, library name, email address, hours and rules with the library.
